## Sobre mim

Estudante de **Sistemas de Informação (8º período)**, com base em infraestrutura e suporte e atuação cada vez mais voltada para **dados**. No dia a dia, trabalho com **troubleshooting**, **análise de dados**, **relatórios** e **dashboards** em um sistema de gestão de transportes (TMS) em produção, usando SQL para investigar problemas, extrair informações e apoiar decisões.

## Experiência

**Azship** · *Suporte Técnico*
> Criação e manutenção de **relatórios** para o sistema, com **otimização de queries** em relatórios lentos. Consultas **SQL** no banco de dados (DBeaver) para análise e investigação. Desenvolvimento de **dashboards** e estudo de **BI**. **Troubleshooting** de sistema em JavaScript (análise de logs e payloads). Validação de código backend no **Bitbucket**.

**Apollo Sistema** · *Auxiliar Técnico*
> Atendimento por ligação e **suporte a clientes**. Soluções com servidor local e instalação de impressoras. **SQL** (select, update, delete) e ajustes no sistema.
